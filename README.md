Explicação de como rodar o jogo: Deve-se executar o arquivo "Trilha dos Desafios.py" no VS Code, através da biblioteca pygame. Essa deve ser instalada através do terminal do sistema operacional em questão, usando do comando "pip install pygame" ou "pip install pygame-ce".
